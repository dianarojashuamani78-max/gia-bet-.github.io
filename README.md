# Gina & Betsabé — Firebase Repository

Repositorio listo para subir a GitHub.

- `firebase-app.js`: código JavaScript proporcionado, conservado sin modificar.
- `README.md`: instrucciones básicas.
- `.gitignore`: archivos del sistema que no se deben subir.

## Configuración necesaria

El código usa Firebase Storage y Cloud Firestore para guardar y compartir fotos, videos y audios. Actualmente contiene valores de configuración de ejemplo (`TU_API_KEY`, `tu-proyecto`, etc.). Deben sustituirse por los datos reales del proyecto Firebase.

El HTML de la aplicación debe cargar las librerías de Firebase y este archivo JavaScript.

## Publicación

Sube los archivos directamente a la raíz del repositorio de GitHub. GitHub Pages puede servir la parte estática; Firebase proporciona el almacenamiento y la sincronización de la galería.
